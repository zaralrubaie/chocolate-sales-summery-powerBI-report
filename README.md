# 🍫 Chocolate Sales Dashboard (Power BI)

##  Project Overview
This project analyzes **chocolate sales performance** using Power BI.  
The dataset was sourced from [Kaggle](https://www.kaggle.com/) and explores sales trends across products, countries, and time.  

The report contains **two pages** with interactive visuals, KPIs, and slicers to help understand sales distribution and performance.  

---

##  Report Structure

###  Page 1 – Sales Overview
- **Cards** → Total Sales  
- **Line Chart** → Monthly Sales Trend (Sum of Sales by Month)  
- **Bar Chart** → Product-wise Sales (legend by Country)  

###  Page 2 – Advanced Analysis
- **Clustered Column Chart** → Quarterly Sales (Sum of Amount by Country)  
- **Treemap** → Country-wise Sales Contribution (Sum of Amount)  
- **Line Chart with Trendline** → Quarterly Boxes Sold  
- **Slicer Filters** → Quarter, Product, Country  

---

##  Key Insights
- Seasonal patterns appear in **monthly and quarterly sales trends**.  
- Strong variation in sales performance across **countries and products**.  
- **Treemap** highlights top-performing countries by sales contribution.  
- Interactive slicers enable flexible drilldowns for deeper exploration.

##  How to Use
1. Download the `.pbix` file and open it in **Power BI Desktop**.  
2. Use the slicers to explore data by **quarter, product, and country**.  
3. View the static version in the included PDF file.
